# ⚠️ IMPORTANTE: Biblioteca de plantillas de rutas

Esta carpeta es SOLO una referencia para crear nuevos agentes.

- NO se carga automáticamente en ningún agente.
- NO debe ser utilizada directamente por el motor.
- Copia manualmente los archivos .yaml que necesites a agents/tu_agente/routes/.
- Luego edita la copia según las necesidades de tu agente.

Para copiar una ruta de ejemplo a un agente existente, usa:
```bash
./scripts/user/copy_route.sh web_search mi_agente
```

No modifiques directamente los archivos aquí si ya los copiaste.
