# Despliegue de FerdoNAN

## Requisitos
- Python 3.14+
- Ollama instalado
- 8GB RAM recomendado

## Instalacion

1. Clonar repositorio
2. Crear entorno virtual: python -m venv venv
3. Activar: source venv/bin/activate
4. Instalar: pip install -r requirements.txt

## Ejecutar

1. Iniciar Ollama: ollama serve
2. En otra terminal: python main.py

## Dashboard

Ejecutar: python web/dashboard.py
